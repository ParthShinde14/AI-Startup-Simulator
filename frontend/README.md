# 🚀 AI Startup Intelligence Platform

An AI-powered startup growth simulation and business intelligence platform built using React, Flask, and MySQL.

This platform simulates how real SaaS startups grow, scale, compete, manage finances, optimize pricing, attract investors, and survive in competitive markets through interconnected business systems and strategic decision-making.

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/yourusername/startup-intelligence-platform.git
```

---

## 2️⃣ Frontend Setup

```bash
npm install
npm run dev
```

---

## 3️⃣ Backend Setup

Create virtual environment:

```bash
python -m venv venv
```

Activate venv:

### Windows

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install flask
pip install flask-cors
pip install flask-sqlalchemy
pip install flask-bcrypt
pip install pymysql
pip install pyjwt
```

Run backend:

```bash
python app.py
```

---

# 🗄️ Database Setup

Create MySQL database:

```sql
CREATE DATABASE startup_simulator;
```

Update database credentials in:

```python
app.config["SQLALCHEMY_DATABASE_URI"]
```
